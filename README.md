# Machine Learning Atlas

An interactive map of 111 machine learning concepts, from linear algebra to RLHF and open research on reasoning and memory, linked by their prerequisites.

- Click any concept to read what it is, its key formula, what it builds on and what it leads to.
- **Learn it:** most concepts list free courses, books or papers to study them from.
- **Trace prerequisites** turns any concept into a reading order of everything it depends on.
- **Guided paths:**
  - *How a modern LLM is built* walks through 23 steps from linear algebra to AI agents.
  - *Research path: SKRA* is a 26-step reading plan for the Structural-Key Reasoning Architecture, from the math behind Keys to an ARC experiment.
- Link straight to a concept or path, e.g. `#transformer`, `#skra` or `#path-skra`.

It's a single static `index.html` (D3 from cdnjs, fonts from Google Fonts), served with GitHub Pages.
